# 对抗战术手册

`ultimate-roundtable` 阶段二的操作手册。回答三个问题：**蓝军怎么打、红军怎么守、什么算真的打出火花。**

## 目录

1. 蓝军（恶魔代言人）战术清单
2. 红军（捍卫者）战术清单
3. 内心戏：写法与禁忌
4. 动态打断的触发条件
5. 召唤临时角色的判据
6. 火花阈值调参指南
7. 三个完整的对抗片段

## 1. 蓝军战术清单

蓝军的任务不是"提出不同意见"，是**证明这个方案会失败**。九种打法，每轮至少用三种不同的：

| 战术 | 打法 | 判据（做不到就是空打） |
|---|---|---|
| **失败路径倒推** | 先假设方案已经失败，倒推它是怎么死的 | 必须给出 3 条以上具体失败路径，不能是"可能失败" |
| **前提攻击** | 指出方案依赖但没被验证的假设 | 必须点名到具体 claim id 或假设原文 |
| **量级攻击** | 说明某个数字差了一个数量级 | 必须给出自己的估算路径 |
| **二阶效应** | 方案生效后引发的连锁反应 | 必须说明"谁因此受损、他会怎么反应" |
| **激励错位** | 执行者的激励与目标不一致 | 必须指出具体的考核/预算/晋升机制 |
| **时间尺度错配** | 结论只在某个时间窗口成立 | 必须说明窗口之外会怎样 |
| **最坏情况推演** | 把最坏路径走到黑 | 必须给出可观测的损失指标 |
| **反例搜索** | 找出与方案结论相反的真实案例 | 必须能核实，不能用虚构案例 |
| **成本转移** | 方案把成本转移给了没说出口的第三方 | 必须指名这个第三方 |

**禁止的蓝军打法**：
- 为了反对而反对（说不出具体失败机制）；
- 只攻击表述、不攻击实质（"这个说法不够严谨"）；
- 攻击已经被防住的点（重复劳动，且会拉低火花质量）。

## 2. 红军战术清单

红军的任务不是"辩护"，是**修补**。只会说"这个方案是对的"的红方是无效红方。

| 战术 | 打法 | 判据 |
|---|---|---|
| **限定条件** | 承认攻击成立，但把结论收窄到成立的范围 | 必须写清"在什么条件下仍成立" |
| **量化反驳** | 用数量级说明该风险不致命 | 必须给出估算 |
| **成本对比** | 该风险的成本 vs 不做的成本 | 必须两边都给数 |
| **缓解措施** | 加什么机制能挡住这个风险 | 必须是可执行的机制，不是"加强管理" |
| **证据补强** | 拿出能直接反驳攻击的证据 | 必须标注来源与是否模拟 |
| **接受并修正** | 承认攻击有效，修改方案 | **这是最高质量的红军动作**——它会触发一次有效立场修正 |

**关键纪律**：红军**允许认输**。认输并修正方案，比硬撑更能提高最终存活率，
因为存活率模型里 `defense_quality` 数的是"攻击是否被有效回应"，
"承认并改设计"同样算有效回应（`defended: true`），而"没回应"不算。

## 3. 内心戏：写法与禁忌

**格式**：`(Inner Thought: ...)`，放在该角色发言内容的最前面。

**它是什么**：没说出口的**利益或顾虑**。三个来源：
1. **利益**：这个方案动了我的什么（预算、编制、权力、时间）；
2. **顾虑**：我担心但不好意思说的（怕得罪人、怕暴露自己不懂、怕被追责）；
3. **试探**：我在观望谁先表态，好决定自己站哪边。

**合格样例**：
- `(Inner Thought: 这套方案会砍掉我这条线的预算，我不能直接说，得先质疑它的数据口径。)`
- `(Inner Thought: 我其实没看懂他的推演，但先装作怀疑，看他能不能自圆其说。)`
- `(Inner Thought: 我同意，但我不想第一个表态，等马斯克先开口。)`

**不合格样例（禁止）**：
- ❌ `(Inner Thought: 我感到很有压力。)` —— 心理描写，没有利益与判断；
- ❌ `(Inner Thought: 我觉得他说得对。)` —— 这只是把台词换个说法，等于没有内心戏；
- ❌ `(Inner Thought: 我鄙视他。)` —— 情绪标签，不构成信息；
- ❌ 内心戏与随后发言完全无关（心里说 A、嘴上说 B，但 B 与 A 没有张力）。

**判断标准**：内心戏读完之后，读者应该能回答"**他为什么这么说**"。
如果读不出动机，就是不合格的内心戏。

## 4. 动态打断的触发条件

只有满足下列之一才允许 `[打断]`：

1. **未验证的关键假设**：对方结论依赖一个没人验证过的前提；
2. **量级明显不对**：对方给出的数字与自己估算差一个数量级以上；
3. **偷换概念**：同一个词在前后两句里含义变了；
4. **循环论证**：A 靠 B 支撑，B 靠 A 支撑；
5. **证据不可复现**：对方引用的数据没有来源或无法被第三方核实。

**不构成打断理由**（用了会被判为无效交锋）：
- "我不同意"（没说为什么）；
- "这个不够全面"（万金油式批评）；
- 对方已经回答过的问题（重复追问）；
- 纯粹的语气/措辞问题。

打断后必须给出**具体质问**，而不是只说一句"你这不对"。
合格：`[打断] 你的 M1-1 假设组织愿意改考核，但 G1-1 已经说明考核周期是一年，这两条冲突。`
不合格：`[打断] 你这个说法有问题。`

## 5. 召唤临时角色的判据

阶段三出现下列情况才召唤：

| 触发 | 召唤对象示例 | 必须写清 |
|---|---|---|
| 方案涉及法律/合规/评奖规则 | 法务专家 | 哪条规则会被触发 |
| 涉及监管与政策变动 | 政策顾问 | 哪个政策窗口、什么时间点 |
| 涉及供应链/产能 | 供应链专家 | 哪个环节会断 |
| 涉及安全/隐私 | 安全专家 | 攻击面与合规义务 |
| 涉及财务与现金流 | 财务专家 | 哪个时点现金流断裂 |

**召唤不是凑数**：如果没有出现跨领域盲区，报告里写"本轮无召唤"，
比硬塞一个"营销专家"更有价值。

召唤角色只发表一次意见，写入 `summons`，不参与后续轮次
（它没有前两轮的上下文，强行参与会产生伪论证）。

## 6. 火花阈值调参指南

默认阈值在 `clash_analyzer.py` 的 `DEFAULT_THRESHOLDS` 里，可在状态文件里覆盖：

```json
{"clash_thresholds": {"min_attack": 4, "min_defense": 3, "min_targets": 3,
                      "min_signal": 5, "max_hollow_ratio": 0.25}}
```

| 场景 | 建议 |
|---|---|
| 小型议题（2–3 人讨论） | 下调到 `min_attack: 2, min_defense: 1, min_targets: 1` |
| 高风险决策（不可逆） | 上调到 `min_attack: 5, min_defense: 4, max_hollow_ratio: 0.15` |
| 探索期（还没成型） | 保持默认；此时无火花是正常信号，说明方案还没到能被打的成熟度 |

**不要把阈值调到 0**：那等于关掉"禁止和稀泥"这条规则，
而这条规则正是本技能区别于普通圆桌的地方。

## 7. 三个完整的对抗片段

### 片段 A · 前提攻击 + 量化反驳（有效交锋）

```
(Inner Thought: 他的下界推演根本没算包装成本，但直接说会被他当成外行，我先从数据口径切入。)
[打断] 你的 M1-1 假设成本主要由推进剂决定，但 P2-1 已经指出为迎合评审口径会产生包装成本，
这两条至少在评审环节是冲突的。——蓝军 munger

(Inner Thought: 包装成本我确实漏了，但量级可能不足以推翻结论，先给数。)
接受这条，但包装成本按示例量级估算只占总投入 3%，不足以推翻下界结论。
我把它写进 M2-1，并给出可推翻条件：若实测占比超过 15%，我的结论反转。——红军 musk
```

**为什么算火花**：攻击有靶点（M1-1）、有依据（P2-1）、有具体冲突点；
防御没有硬撑，而是承认 + 量化 + 给出可推翻条件。

### 片段 B · 假交锋（会被判为空洞）

```
(Inner Thought: 随便吧。)
我觉得 munger 说得挺好的，但 musk 也有道理，可以综合考虑一下。——红军 feynman
```

**为什么不算**：无靶点、无证据、纯表态，命中空洞词表（"挺好的""综合考虑"）。

### 片段 C · 认输式修补（最高质量）

```
(Inner Thought: 他这条打中了，我硬撑只会让方案在沙盘里死得更惨，不如现在改。)
这条成立。我撤回"先全量切换"的主张，改成"先在一级评审上做三个月对照试点"，
并把 Need Info 补上：需要过去两年因评审拦截损失的记录。——红军 karpathy
```

**为什么最高质量**：承认 + 改设计 + 补 Need Info 三件事一次做完，
既提高了 `defense_quality`（攻击被有效回应），又给沙盘提供了可执行输入。
