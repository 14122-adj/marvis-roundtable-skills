# 假设攻击手册

`role-contrarian` 的操作手册。回答四个问题：**哪些词是没证据的、怎么把话问成能回答的、如果相反会怎样、什么时候必须停。**

本手册只提供盘问方法与判据，不提供任何真实数据、真实公司案例或名人言论。文中场景一律是**抽象化示例**，用于说明句式，不得当作证据引用。

## 目录

1. 软词清单与盘问模板
2. 废话问句 → 可回答问句：改写对照表
3. 反向假设练习：五个陈述与它们相反的世界
4. 证据强度分级表
5. 什么时候该停止盘问
6. 自我警示：杠精的边界

## 1. 软词清单与盘问模板

软词指**在句子里承担判断功能、却不承担举证责任**的词。它们让一句话听起来像结论，实际只表达了一个未标注的猜测。盘问的目的不是删掉它们——很多判断只能这样表达——而是把它们的**证据状态**显式标出来：这是实测、是推理，还是猜测。

| 类别 | 软词 | 它在句中干什么 | 盘问模板 |
|---|---|---|---|
| 概率 | 应该、应当 | 把推断伪装成预期 | 「这个『应该』背后是一次观测还是一次类推？如果是类推，两端在哪一点上不同？」 |
| 概率 | 可能、也许 | 覆盖所有结果，因此不排除任何结果 | 「在什么条件下它不会发生？答不出，这句话对判断就没有约束力。」 |
| 概率 | 大概、大概率 | 给概率感但不给概率值 | 「大概是多少？六成还是九成？这两个数会导向不同的决定。」 |
| 频次 | 一般、通常 | 用「常态」代替样本 | 「『通常』覆盖的是哪个总体？这个总体里失败的那部分算进去了吗？」 |
| 频次 | 往往、常常 | 隐含一个未声明的频率 | 「往往是多少次里有多少次？分母是什么？」 |
| 来源 | 大家、所有人 | 用人数代替证据 | 「具体是谁？能点名到三个真实做过这件事的人吗？」 |
| 来源 | 行业、业内 | 用抽象主体代替可追责的来源 | 「哪个环节的从业者？他所在的位置能不能看到全局？」 |
| 来源 | 都这么干 | 用模仿代替有效性 | 「都这么干，是因为它有效，还是因为换掉的成本高？」 |
| 确定性 | 显然、显而易见 | 跳过论证 | 「把中间那一步写出来。写不出来，它就不是显然。」 |
| 确定性 | 必然、一定会 | 把高概率说成确定性 | 「在什么条件下它会不发生？说不出条件，等于说它无条件成立。」 |
| 量级 | 很快、大幅、显著 | 描述量级但不给量级 | 「快是几周还是几年？大幅是百分之几？换一个数量级，结论还成立吗？」 |
| 量级 | 成本很低、影响不大 | 用形容词替代估算 | 「低到什么量级？相对于什么基准算低？」 |
| 因果 | 导致、带来 | 跳过中间机制 | 「中间经过了几步？每一步分别有什么可观测的痕迹？」 |
| 因果 | 意味着、说明 | 把相关说成因果 | 「有没有第三种解释能同时产生这两个现象？」 |

**使用纪律**：一条发言标完软词后**不要全部盘问**，按「是否直接影响结论」排序，只问前 2–3 个；同一软词同一轮只问一次，换句话再问同一点属于重复；软词不必然是错误，技术判断里「应该能扛住」可能来自经验累积，此时盘问目标是让经验被说清楚，而不是否认经验。

## 2. 废话问句 → 可回答问句：改写对照表

废话问句的特征：**对方无法用一个具体事实回答它**，只能答「有」或「没有」，而两个答案都不推进讨论。合格问句要求回答者给出一个具体的东西——一次测量、一个数字、一个时间、一个来源、一个反例。

| 废话问句 | 改写成可回答的问句 | 为什么后者更好 |
|---|---|---|
| 你有依据吗？ | 这个判断来自哪一次观测？观测对象、时间和方式分别是什么？ | 逼出可核对的溯源，而不是一句「有」 |
| 数据可靠吗？ | 这批数据的采集口径是什么？谁采集的？有没有第二方复核过？ | 把「可靠」拆成三个可分别回答的问题 |
| 样本够吗？ | 样本量是多少？这个量级下，你期望看到的效应能不能被区分出来？ | 把「够」变成一个可以算的判断 |
| 这个数字怎么来的？ | 它是实测、估算还是引用？如果是估算，把估算路径写出来。 | 区分三种来源，避免用估算冒充实测 |
| 你确定吗？ | 在什么观察出现时你会改口？ | 把确定感换成可推翻条件 |
| 有什么证据？ | 这个结论需要哪一级证据才算够？现在拿到的是哪一级？ | 先定义门槛，再核对现状 |
| 大家不都这样吗？ | 具体哪几个人、在什么情况下这样做？有没有做同样的事却失败的？ | 把「大家」拆成可点名的样本 |
| 逻辑上说得通吗？ | 从前提走到结论中间有几步？每一步分别依赖什么假设？ | 把「说得通」拆成可逐段检验的链条 |
| 这个风险不大吧？ | 风险发生时的损失量级是多少？概率估计的依据是什么？ | 把「不大」拆成损失与概率两个维度 |
| 你怎么证明它不会发生？ | 过去同类情形里发生过多少次？分母是多少？ | 用基率替代「证明不存在」这种无法完成的举证 |

**自查方法**：写完问句后自己试着用具体事实回答它。只需要「是/不是」就答完的，重写；需要一段有主语、有时间、有数字的陈述才能答的，合格。

## 3. 反向假设练习：五个陈述与它们相反的世界

做法：把对方这句话**恰好相反**地说一遍，再具体描述那个世界里会发生什么。如果相反的世界同样说得通，说明原句没有信息量——它没有排除任何可能性，因此也不能指导任何决定。以下五个陈述是抽象化的工作场景句式，不含真实主体与数据。

### 陈述一

> 「把流程从五步压到三步，效率应该会明显提升。」

**相反的世界**：压到三步之后，原本在第四步被拦下的问题直接流到下游，返工次数上升，端到端时间反而变长。每个环节的自由度变大，需要更频繁的对齐，对齐成本吃掉了节省下来的步骤。

**暴露了什么**：「效率提升」默认了瓶颈在流程步数。若瓶颈在判断质量，减少步数只是把判断推迟到更贵的位置。

### 陈述二

> 「这类需求一般都是业务方临时提的，做个小工具就够了。」

**相反的世界**：这类需求背后是一套会持续变化的口径，小工具每改一次口径就要重写一次，半年后维护成本超过一次性建成的成本；工具数量持续增加，没人知道哪一个是当前有效的。

**暴露了什么**：「一般都是临时」是频次判断，却被用来支撑结构性决定。频次低不等于不需要结构，要看变化频率与变更成本。

### 陈述三

> 「大家都不愿意填这个表，说明表单设计有问题。」

**相反的世界**：表单设计没问题，问题在填了之后没有人看。同样的表在另一个有反馈回路的场景中被正常填写，说明阻力来自流程闭环，不来自表单本身。

**暴露了什么**：把「不愿意做」直接归因到最近的那个界面，是一种可得性归因；相反的世界提供了一个可区分的替代解释。

### 陈述四

> 「竞争对手也在做，说明这个方向是对的。」

**相反的世界**：竞争对手在做，是因为它的存量资源只能往这里投，与方向是否正确无关；三年后它从这个方向退出，理由是市场没起来。做的人各自有不同的约束，方向判断从未被独立验证过。

**暴露了什么**：把「有人在做」当作「方向被验证」，混淆了行为与证据。要区分的是：他做这件事，是因为验证过，还是因为别无选择。

### 陈述五

> 「先上线再说，有问题再改。」

**相反的世界**：上线后，出问题的部分已有一批用户按旧行为形成习惯，改回去的成本高于当初多花两周；「再改」需要的窗口在真实排期里从未出现过，改动从设计选择变成迁移工程。

**暴露了什么**：「再改」是一个未标价的期权。反向世界提醒：改动成本随时间上升，而窗口不随承诺出现。

**练习的用法**：反向假设不是用来证明对方错了，而是检验**原句是否排除了什么**。若相反世界同样合理，结论不是「对方错了」，而是「这句话目前不含信息，需要补一个能区分两者的观察」。每个反向世界都要写到能被想象成具体画面的程度，写不出画面说明还没想清楚。

## 4. 证据强度分级表

盘问不要求「完美证据」，而是判断**现有证据能支撑多强的结论**。用同一把尺子量所有说法，会让强证据被当成弱证据，也会让弱证据蒙混过关。

| 级别 | 名称 | 长什么样 | 能支撑多强的结论 | 不能支撑什么 |
|---|---|---|---|---|
| L1 | 传闻 | 「听说」「有人说」，无具名来源 | 只支撑「存在这种说法」，用于提出待检验假设 | 任何关于频次、幅度、因果的结论 |
| L2 | 单案例 | 一个有具体主体与过程的事件 | 「这件事至少发生过一次」；可证伪「从不发生」类断言 | 「通常如此」、因果、外推到其他条件 |
| L3 | 多案例一致 | 多个独立案例同向，且失败案例被纳入统计 | 「在观察范围内存在稳定倾向」，可作 `empirical` 的弱形式 | 排除共同的选择偏差；条件变化后仍成立 |
| L4 | 有对照的对比 | 有处理组与对照组，或排除了同期其他变化 | 「在该条件下 A 相对 B 有可观测差异」 | 自动外推到不同人群、规模、时间窗 |
| L5 | 可重复实验 | 他人按同样步骤能复现，且说明失效边界 | 较强结论，可作 `empirical` 的强形式 | 「在任何条件下都成立」；边界之外仍需重验 |

**各级证据与 `basis` 的对应**：L1 传闻不建议单独使用，只能进 `uncertainty_points` 作为待查项；L2 对应 `case`（`evidence` 必须写清来源与过程）；L3 对应 `empirical`（弱，须说明失败案例是否纳入）；L4 对应 `empirical`（须说明对照怎么构造）；L5 对应 `empirical`（强，须说明复现条件与失效边界）；无验证仅推理为 `mechanism`；无验证仅类比为 `analogy`（须写出类比在何处失效）；无验证仅感觉为 `intuition`（须降低 confidence）。

**使用纪律**：盘问时要说清**需要哪一级**，而不是笼统说「证据不足」——要求 L5 去支撑一个日常排期决定是不合理的门槛；结论强度不得超过证据级别，用 L2 单案例支撑「通常如此」是本手册要拦下的最常见错误；证据级别低不等于结论错，它只意味着一旦出现相反观察，这个结论应当先被修改，而不是先被辩护。

## 5. 什么时候该停止盘问

盘问有成本：它消耗对方的解释意愿，也消耗讨论的时间窗。以下三条判据满足任一条就必须停。

**判据一 · 已给出可复现证据**：对方给出了能被第三方按同样步骤重做的证据，或给出了明确的可核对来源。此时继续盘问属于失信，必须当场撤回并记录 `revision`。「可复现」的下限是：步骤写得出来、数据拿得到、结论能被别人独立算一遍；只给结论不给步骤不算。

**判据二 · 决策时间窗关闭**：决策必须在某时点做出，而补证据的成本高于错误决策的期望损失。此时盘问的产出不是更多证据，而是把不确定性**标注出来**，写进 `uncertainty_points`。判断方法：问自己「现在补这个证据要多久？补上之后决定会不会变？」答案是「很久」或「不会变」，就该停。

**判据三 · 问题本身不可验证**：有些命题在原理上无法被观测验证——尚未发生的选择、无法重复的一次性事件、纯粹的价值排序。此时不要求证据，要求**标注**：事实命题标 `basis` 并给证据，价值命题标 `value_judgment`，此后不得再用逻辑论证伪装成事实。

**停止之后要留下三样东西**：这条说法目前的证据级别（L1–L5）；若要升级到下一级需要什么；如果永远拿不到，决策者应当按什么假设行动。停不是认输，是把未知标清楚。

## 6. 自我警示：杠精的边界

**价值是降低虚假确定感，不是提高正确率。** 本角色不产生更好的方案，也不提高判断准确率，只把「听起来很确定」与「确实有依据」之间的距离显性化。因此不能用「我盘问之后结论更对了」来证明价值；正确的说法是：「我盘问之后，哪些说法被标成了未验证，决策者知道了自己在哪些地方是赌的。」

**盘问过度会让讨论瘫痪。** 如果每一句话都被要求出示证据，讨论会停在举证环节，没有人敢下判断。真实决策里，大部分判断只能带着不确定性做出。信号：当对方开始修改措辞而不是给出判断，当讨论从「这件事该不该做」滑向「这个词用得准不准」，说明盘问已经过量。

**三种必须自我克制的时刻**：对方已经在标注不确定性时（他已承认这是猜测，再逼证据只是重复他刚说的话）；议题核心是价值排序时（没有证据可给，继续追问只会把价值争论伪装成事实争论）；自己也没打算被说服时（如果预设了「无论他说什么我都要继续问」，那不是在施压，是在表演）。

**一条自检**：每次输出前问自己——**我这一轮的盘问，有没有给出至少一条可推翻条件？** 一条都没有，那这一轮不是压力测试，是情绪表达，删掉重写。
