### 详细描述（大文本框）

复制下面整段（中文版）：

```
大多数多智能体讨论技能，产出的是六份互相恭维的备忘录——没人被逼着证明什么，最后什么也没决定。

这个技能让六个人互相拷问，并且只允许一种结尾：一个决定。

【四个真正起作用的东西】

1. 拒绝角色扮演
每个角色跑的是强制思维协议，不是人设服装。马斯克必须拆到物理约束并给出量级估算；费曼必须用外行话讲清否则标记"未理解"；芒格必须先反向问"怎么才能保证它失败"；乔布斯必须回答"这更简单还是更复杂"；Karpathy 必须让每条论断可复现；Paul Graham 必须从真实案例起手。模糊表述在校验阶段就被拒绝，不会留到最后。

2. 死锁熔断
内置语义级死锁检测。当双方只是在换说法复读（同样的论点、不同的词、不同的例子），系统切断辩论、强制进入裁决。逐字重复容易抓，换说法才是难点，这里抓的就是后者。

3. 可执行的产出，不是摘要
收尾只有三样东西：三个互斥方案（激进 / 保守 / 降维）、六人强制投票、一个决定。然后是一张命令单：负责人、第一步、带数字的 KPI、带数字的止损线。写"如果效果不好就停止"会被校验器拒绝——模糊是一种构建错误。

4. 零摩擦
附带一键跑通与交互式向导。python tools/quickstart.py：体检 → 跑完一场完整讨论 → 自检 → 下一步，约 10 秒，无需配置、无需 API key、无依赖。python tools/wizard.py：交互式生成你自己的五个阶段配置，边填边校验。

【还包含】

· 诚实标注：每个数据点都标为真实工具或模拟数据，报告头部直接印出比例。缺标注会被拒绝——模拟数据不能冒充真实。
· 注意力分舱：每个角色只看到与自己视角相关的历史，避免上下文过载变成一锅粥。
· 少数派保护：未被有效反驳的少数派观点完整保留，不会被多数票淹没。
· 平民视角审计：六人全票通过时提醒你——盲区通常属于那个真正要用它的人。
· 跨会话记忆：经验在多次运行之间沉淀（纯 JSONL 文件）。

【安装】

把文件夹放进你的 agent skills 目录：
  Claude Code    ~/.claude/skills/ultimate-roundtable/
  Cursor / Cline <项目>/skills/ultimate-roundtable/
  马维斯        技能管理 → 导入技能 → 选 SKILL.md
  其他（读 AGENTS.md 的）   <项目>/skills/ultimate-roundtable/

然后对它说：「开启终极圆桌：要不要把年度评审改成季度评审」

【自定义宿主环境】

如果你的宿主不支持 ZIP 导入，克隆 GitHub 仓库后运行 python tools/quickstart.py，30 秒即可。

【要求】

Python 3.9+，仅用标准库，无需安装任何依赖。
支持 Claude Code、Codex、Cursor、Cline、Windsurf，以及任何读取 SKILL.md 的 agent。
```
